STEP 1: Create GitHub Account (Skip if you already have one)
─────────────────────────────────────────────────────────────────────────────

1. Go to: https://github.com/join
2. Click "Sign up"
3. Enter email address
4. Create password
5. Choose username (this will be in your website URL)
6. Verify your email
7. Complete setup

⏱️ TIME: 2 minutes

STEP 2: Create a New Repository
─────────────────────────────────────────────────────────────────────────────

1. Go to: https://github.com/new
   (Or click "+" icon in top right → New repository)

2. Fill in the form:

   Repository name:
   └─ Type: disaster-prediction
   
   Description:
   └─ Type: Disaster Prediction System
   
   Public/Private:
   └─ Select: PUBLIC (must be public for free hosting)
   
   ✓ Add a README file
   └─ Check this box

3. Click: "Create repository" (green button)

4. Wait for it to load...

⏱️ TIME: 1 minute

═════════════════════════════════════════════════════════════════════════════

STEP 3: Upload Your index.html File
─────────────────────────────────────────────────────────────────────────────

1. You should now be on your new repository page
   URL looks like: https://github.com/YOUR-USERNAME/disaster-prediction

2. Click the "Add file" button (top right area)
   └─ Select: "Upload files"

3. Now you have two options:

   OPTION A - Drag & Drop (Easiest):
   ├─ Find index.html on your computer
   ├─ Drag it to the upload area on the web page
   └─ Release it

   OPTION B - Click to Browse:
   ├─ Click "choose your files"
   ├─ Navigate to index.html
   ├─ Select it
   └─ Click "Open"

4. After file appears in the upload area, scroll down

5. Under "Commit changes", add a message:
   └─ Type: "Initial commit: Add disaster prediction website"

6. Click: "Commit changes" (green button)

7. Wait for upload to complete...

⏱️ TIME: 1 minute

═════════════════════════════════════════════════════════════════════════════

STEP 4: Enable GitHub Pages
─────────────────────────────────────────────────────────────────────────────

This is the MOST IMPORTANT step - it makes your website live!

1. Go to your repository: https://github.com/YOUR-USERNAME/disaster-prediction

2. Click: "Settings" (tab at top of the page)

3. On the left sidebar, scroll down and find: "Pages"
   └─ Click on "Pages"

4. Under "Build and deployment" section:

   Under "Source":
   └─ Click the dropdown that says "None"
   └─ Select: "main" (your main branch)
   └─ Click "Save"

5. Wait 1-2 minutes for GitHub to process...

6. A green message will appear saying:
   "Your site is live at: https://YOUR-USERNAME.github.io/disaster-prediction"

⏱️ TIME: 2 minutes

❓ FREQUENTLY ASKED QUESTIONS:
─────────────────────────────────────────────────────────────────────────────

Q: Why doesn't my website show up immediately?
A: GitHub needs 1-2 minutes to deploy. Refresh after 2 minutes.

Q: My website shows 404 error
A: Make sure:
   ✓ Repository is PUBLIC (not private)
   ✓ Pages is enabled in Settings
   ✓ index.html is in the root of the repository
   ✓ Wait 2 minutes and refresh

Q: Can I use my own domain instead of github.io?
A: Yes! Go to Settings → Pages → Custom domain
   (Requires buying a domain elsewhere)

Q: Can other people edit my website?
A: No! Only you can edit it (unless you give them access).
   The website is read-only for visitors.

Q: Is it secure (HTTPS)?
A: Yes! GitHub Pages automatically provides HTTPS/SSL.

Q: Can I host multiple websites?
A: Yes! Create multiple repositories with different names.

Q: Will my website disappear if I don't use it?
A: No! GitHub Pages never expires as long as your account exists.

Q: Can I add real data (USGS, NOAA APIs)?
A: Yes! Update the JavaScript code in index.html to fetch real data.

🆘 TROUBLESHOOTING:
─────────────────────────────────────────────────────────────────────────────

Problem: Settings tab doesn't show "Pages"
Solution: 
  ✓ Make sure you're on the repository settings (not account settings)
  ✓ Scroll down in the left sidebar
  ✓ Look for "Pages" under "Code and automation" section

Problem: Website shows "404 Not Found"
Solution:
  ✓ Check repository is PUBLIC
  ✓ Verify index.html is uploaded to main branch
  ✓ Go to Settings → Pages and check Source is "main"
  ✓ Wait 2-3 minutes and refresh

Problem: Changes to index.html don't show on website
Solution:
  ✓ Clear your browser cache (Ctrl+Shift+Delete or Cmd+Shift+Delete)
  ✓ Do a hard refresh (Ctrl+F5 or Cmd+Shift+R)
  ✓ Wait a minute for GitHub to rebuild the page

Problem: The website looks broken/ugly
Solution:
  ✓ Make sure entire index.html file was uploaded correctly
  ✓ Right-click on website → "Inspect" to check for errors
  ✓ If file is incomplete, delete and re-upload
